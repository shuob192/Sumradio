# Sumradio

無線交信をマイクから文字起こしし、人間が確認するタスク候補と地図に整理するローカルアプリです。

## 初期版

実行可能なアプリ一式は **[App/](App/)** にあります。既存の企画・発表資料はそのまま残しています。

- 架空地名の青葉地区と、東京都内の実在地名を使う訓練デモ
- 開始時の都道府県・市区町村指定と、実施回ごとの記録保存
- マイク録音、字幕、タスク候補・未対応・対応済みボード
- 原文を残した聞き取り確認と、登録地点をワンタッチで承認して地図表示
- 🩸負傷者、🚑救助・搬送など15種類の記号と、複数分類の表示

## 起動

Apple Silicon Mac、Python 3.12、uv、Node.js、pnpmを使用します。依存関係・音声モデルの準備とCodex CLI認証が必要です。

```sh
cd App
uv sync --frozen
cd frontend
pnpm install --frozen-lockfile
pnpm build
cd ..
uv run --frozen sumradio prepare-model
uv run --frozen sumradio serve
```

詳しくは **[セットアップ・操作手順](App/README.md)** を参照してください。準備後は [App/Sumradioを起動.command](App/Sumradioを起動.command) から起動できます。接続先は `http://127.0.0.1:8765` です。

音声モデル、認証情報、録音、実施回データ、依存ライブラリ、配信用ビルド結果はリポジトリに含めません。位置マスターには訓練用の登録地点のみを含みます。実在地名デモの状況・人数・要請は架空です。
