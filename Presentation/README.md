# Presentation

当日のデモや発表で使用する資料を保存するフォルダです。

スライド、デモ進行表、発表原稿、配布資料などを配置します。

- [10分プレゼンスライド（PowerPoint）](Sumradio_10min.pptx)：編集可能な12枚。発表者ノートに原稿、時間配分、出典を収録。
- [10分プレゼンスライド（PDF）](Sumradio_10min.pdf)：表示確認・共有用。
- [10分プレゼン構成案](10分プレゼン構成案.md)：本編12枚、デモと時間の余裕を含む10分用。
- [5分構成案](発表構成案.md)：短縮版と採点基準・出典の整理。

スライドは本編9分と、ライブ処理待ち・切り替えの余裕1分で構成しています。5枚目でアプリのライブデモへ切り替えます。アプリ実画面・操作動画・開発ログは未収録で、地図と抽出例は仕様に基づく説明イメージです。GUIデバッグの説明は開発経緯に基づくもので、実測の自動化率は掲載していません。発表前に実際の動作・使用記録と照合してください。

使用フォントはHiragino Sansです。別環境では代替フォントにより改行が変わる場合があります。PDF版で意図した配置を確認できます。[画像の出典と生成方法](assets/README.md)も参照してください。

製品仕様は[要件定義](../Document/要件定義.md)と[技術仕様](../Document/技術仕様.md)、デモの発話と期待結果は[無線交信台本](../Document/無線交信台本.md)を参照します。[発表構成案](発表構成案.md)はこれらを発表用に要約した資料です。仕様変更時は対応する説明・デモ・将来計画を更新し、実装や実測の記録がある内容だけを実績として発表します。
