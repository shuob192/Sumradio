# Sumradio Agent Guide

## Project context

- Repository: `shuob192/Sumradio`
- This project is maintained collaboratively by three contributors.
- Keep changes focused, reviewable, and easy for the other contributors to understand.

## Working agreements

- Create a dedicated branch for each feature or fix.
- Do not commit secrets, credentials, local configuration, or generated build artifacts.
- Avoid unrelated formatting or refactoring in the same change.
- Update documentation and tests when behavior changes.
- Before committing, run the relevant formatter, checks, and tests when available.
- Write concise commit messages that describe the intent of the change.

## Pull requests

- Explain what changed, why it changed, and how it was verified.
- Keep pull requests small enough to review safely.
- Call out breaking changes, migrations, or unresolved concerns explicitly.
- Do not merge while required checks are failing.
